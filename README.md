# Vivavere

Home of `vivavere.com`. For now this repo only holds the infrastructure for the
domain and its email (`contact@vivavere.com`, hosted on Migadu) — see
[`infra/README.md`](infra/README.md).

This repo is **public**. Nothing secret or account-specific is committed here:
operator config (`prod.tfvars`, the bootstrap record) and any future secrets
live in the private `Absence0760/infra-secrets` repo under `vivavere/`.
